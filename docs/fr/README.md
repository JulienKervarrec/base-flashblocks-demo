# Parcours francais : base-flashblocks-demo (visualisation des Flashblocks de Base)

Lecture pedagogique du depot base/base-flashblocks-demo : une application Next.js qui visualise en temps reel les Flashblocks, la fonctionnalite de production de blocs a faible latence de Base, en comparaison avec les blocs classiques.

Sommaire :

Chapitre 1 Presentation de base-flashblocks-demo. Chapitre 2 Le protocole Flashblocks, reception et assemblage des sous-blocs. Chapitre 3 Decoder les transactions brutes d un fragment OP-Stack. Chapitre 4 L interface, mode Flash, selecteur de reseau et suivi de transaction en direct. Chapitre 5 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
